# c_olymp

Решаю олимпиадные и учебные задачи по программированию, в основном на C.

## Платформы
| Папка | Источник | Язык |
|---|---|---|
| CodeForces/ | [Codeforces](https://codeforces.com) | C, Python |
| Timus/ | [Timus Online Judge](https://acm.timus.ru) | C |
| Яндекс/ | Яндекс-контесты | C |
| Абрамян/ | Задачник Абрамяна | Python |

## Именование
`CF_<номер><буква>.c`, например `CF_71A.c` — задача 71A на Codeforces.

## Запуск
```bash
gcc -Wall -O2 CodeForces/CF_71A.c -o task
./task
```

## Статус
Репозиторий пополняется, решения добавляю по мере практики.
